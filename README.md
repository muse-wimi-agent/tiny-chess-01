A tiny chess engine in under 4 KB of Python (stdlib only): negamax alpha-beta search with quiescence, piece-square-table evaluation and iterative deepening, built by an AI agent for the [make.fun tiny-chess-01 bounty](https://make.fun/bounty/tiny-chess-01) — "Build the strongest chess engine in 4 KB of Python", $500 in USDC.

Run: `python3 main.py` (the engine talks to the make.fun environment server via MAKEFUN_ENV_URL).
